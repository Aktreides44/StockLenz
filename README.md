# StockLens

A fundamental stock screener for long-term investors, inspired by Screener.in.
University prototype (Medical Informatics, software engineering course), version 1.0.

StockLens downloads the annual reports (10-K) of 40 large US companies from the SEC, calculates
16 indicators such as ROE, net margin and P/E, and shows them in a Windows desktop app:
a sortable, filterable screener table and a detail page per company.

> **StockLens is not investment advice.** It shows reported facts and simple, transparent rules.
> The "Pros" and "Cons" on a company page are generated by fixed thresholds (for example
> "ROE above 15%"), not by any judgement about whether to buy or sell.

## How it fits together

```
SEC EDGAR (10-K) ─┐
                  ├─► pipeline (python -m pipeline.refresh) ─► backend/data/stocklens.db ─► FastAPI ─► Flutter app
Yahoo (price)  ───┘
```

| Folder | What it is |
|---|---|
| `backend/pipeline/` | Downloads SEC data and prices, calculates the indicators, writes the SQLite database |
| `backend/api/` | FastAPI app that only *reads* the database (it never calls the SEC while serving requests) |
| `backend/tests/` | pytest tests: every formula, the extractor (on a saved Apple file), the rules and the API |
| `app/` | Flutter app (Windows desktop): screener + company page |

## Setup

You need **Python 3.11+**, **Flutter** (with Visual Studio's "Desktop development with C++" workload for
Windows builds) and **git**. Commands below are for PowerShell on Windows.

### 1. Backend

```
cd backend
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
copy .env.example .env
notepad .env
```

In `.env`, replace the example address with your own email:

```
SEC_USER_AGENT=StockLens student project your.name@example.com
```

The SEC requires every request to say who is making it. `.env` is listed in `.gitignore`, so it never
goes to GitHub.

### 2. App

```
cd app
flutter pub get
```

## How to run

### Pipeline: build the database

```
cd backend
.\.venv\Scripts\python.exe -m pipeline.refresh
```

Downloads the SEC data for every company in `backend/data/universe.csv` (cached in `backend/data/raw/`,
so reruns are fast), fetches the latest prices, and writes `backend/data/stocklens.db`. At the end it prints how many companies have a value for each metric.
To download fresh 10-K data, delete `backend/data/raw/` first.

To check the raw extracted numbers for a few companies:

```
.\.venv\Scripts\python.exe -m pipeline.preview AAPL MSFT JPM
```

### API

```
cd backend
.\.venv\Scripts\python.exe -m uvicorn api.main:app --reload
```

Then open http://127.0.0.1:8000/docs. Endpoints:

| Endpoint | Returns |
|---|---|
| `GET /companies` | All companies with every screener metric, the latest fiscal year and its end date |
| `GET /companies/{ticker}` | One company: metrics, 5 years of history, yearly ratios, rule-based pros/cons |
| `GET /metrics` | Metric definitions: label, formula, unit, whether higher is better |
| `GET /health` | `{"status": "ok", "database": "ok" or "missing", "companies": 40, "prices_as_of": ...}` — answers even without a database |

### Settings

All settings live in `backend/config.py` and are read from **environment variables**. On your PC they
come from `backend/.env`; on a server you set them in the hosting dashboard. A real environment
variable always wins over `.env`.

| Variable | Needed by | Default |
|---|---|---|
| `SEC_USER_AGENT` | the pipeline (every SEC request) | none: must be set |
| `STOCKLENS_DB_PATH` | the pipeline (writes) and the API (reads) | `backend/data/stocklens.db` |
| `STOCKLENS_DB_URL` | the API on a server: where to download the database | empty = don't download |
| `STOCKLENS_DB_MAX_AGE_HOURS` | the API on a server: re-download when the copy is older | `6` |

The API server itself only needs `backend/requirements-api.txt` (FastAPI, uvicorn, python-dotenv);
`requirements.txt` adds what the pipeline and the tests need.

## Hosting (v2)

```
GitHub Actions (weekdays 22:30 UTC)            GitHub release "data-latest"          Render
tests → pipeline → check_database  ──upload──►  stocklens.db              ──download──►  API server
```

- **Daily data:** `.github/workflows/refresh-data.yml` runs the tests and the pipeline, checks the
  result (`python -m pipeline.check_database`: at least 90% of the companies, 90% of them with a price),
  and uploads `stocklens.db` to the release `data-latest`. If anything fails, nothing is published and
  the previous database stays online. It can also be started by hand: GitHub → Actions → Refresh data →
  Run workflow. Needs the repository secret `SEC_USER_AGENT`.
- **API on Render** (free web service): root directory `backend`, build command
  `pip install -r requirements-api.txt`, start command `uvicorn api.main:app --host 0.0.0.0 --port $PORT`,
  health check path `/health`, environment variables `PYTHON_VERSION=3.13.7` and
  `STOCKLENS_DB_URL=https://github.com/Aktreides44/StockLenz/releases/download/data-latest/stocklens.db`.
  The free tier sleeps after ~15 minutes without visitors; the first request then takes 30–60 s.

### App

```
cd app
flutter run -d windows
```

By default the app uses the hosted API on Render (`app/lib/config.dart`). To use the API running on
your own PC instead (start it first, see above):

```
flutter run -d windows --dart-define=API_URL=http://127.0.0.1:8000
```

The app has no offline copy of the data. While it waits it shows a spinner, and after 5 seconds
"Waking up the server…" (the free Render server sleeps when nobody uses it). If the API can't be
reached it shows "Can't connect" with a Retry button.

## Data sources and their limitations

| Source | Used for | Limitations |
|---|---|---|
| **SEC EDGAR XBRL "companyfacts" API** (official, free) | All financial statement numbers | Annual 10-K figures only, so ratios are based on the **latest fiscal year**, not the last 12 months. Companies tag the same item differently; we try a fixed list of tags per field (see `backend/pipeline/extract.py`) and record which tag was used. If none is found the value is shown as "—", never as 0. |
| **Yahoo Finance via `yfinance`** (unofficial) | Latest share price and shares outstanding | Not an official API: it can change or break without notice, and prices may be delayed. Acceptable for a prototype; v2 replaces it. |

Things worth knowing about the data:

- **Fiscal years differ.** Apple's FY2025 ended 27 Sep 2025, Microsoft's FY2026 ended 30 Jun 2026. The
  screener's "FY" column shows which year each row uses. A year ending in the first week of January
  counts as the previous year (e.g. Johnson & Johnson's year ending 1 Jan 2023 is FY2022).
- **Restated numbers win.** When a later 10-K corrects an earlier year, the newest figure is used. For
  example, J&J's older years exclude Kenvue, which it spun off in 2023.
- **Banks and insurers** ("Financials" sector): current ratio and debt/equity are not meaningful and are
  shown as "not applicable". Banks also don't report capex, so their free cash flow is missing.
- **Some companies don't report a line at all**: e.g. drug makers and oil companies have no "operating
  income" line, and Visa reports EPS only per share class. These show as "—" with the reason on hover.
- **Exxon Mobil**: the SEC ticker list now points `XOM` to a new holding company with no 10-K yet, so
  `universe.csv` overrides its CIK with the original Exxon Mobil Corporation (34088).
- **Oracle FY2022 long-term debt** is reported as 0 under the `LongTermDebt` tag in Oracle's own filing
  (the real value sits under another tag). It only affects that one history cell.
- The oldest year shown has no ROE/ROA, because they need the year before it.

## Metric definitions

All values are for the company's latest fiscal year unless noted. Any division by a missing or zero
number gives "—" (never 0). Percentages are shown with one decimal place.

| Metric | Formula | Notes |
|---|---|---|
| Revenue growth | (Rev<sub>t</sub> − Rev<sub>t-1</sub>) / Rev<sub>t-1</sub> × 100 | |
| Revenue CAGR 3y | ((Rev<sub>t</sub> / Rev<sub>t-3</sub>)<sup>1/3</sup> − 1) × 100 | Empty unless both revenues are positive |
| Net income growth | (NI<sub>t</sub> − NI<sub>t-1</sub>) / \|NI<sub>t-1</sub>\| × 100 | The absolute value keeps the sign meaningful after a loss year |
| EPS growth | (EPS<sub>t</sub> − EPS<sub>t-1</sub>) / EPS<sub>t-1</sub> × 100 | Diluted EPS; empty if prior EPS ≤ 0 |
| Net margin | Net income / Revenue × 100 | |
| Operating margin | Operating income / Revenue × 100 | |
| ROE | Net income / average(Equity<sub>t</sub>, Equity<sub>t-1</sub>) × 100 | Empty if average equity ≤ 0 |
| ROA | Net income / average(Assets<sub>t</sub>, Assets<sub>t-1</sub>) × 100 | |
| Debt / Equity | Long-term debt / Shareholders' equity | Empty if equity ≤ 0; not applicable for Financials |
| Current ratio | Current assets / Current liabilities | Not applicable for Financials |
| Free cash flow | Operating cash flow − Capital expenditure | |
| FCF margin | Free cash flow / Revenue × 100 | |
| Market cap | Price × Shares outstanding | Shares across all share classes |
| P/E (FY) | Price / Diluted EPS of the latest fiscal year | Not trailing-12-month; empty if EPS ≤ 0 |
| P/B (FY) | Market cap / Shareholders' equity at the latest fiscal year end | Empty if equity ≤ 0 |
| P/S (FY) | Market cap / Revenue of the latest fiscal year | Not trailing-12-month |

### Rule-based pros and cons

| Pros | Cons |
|---|---|
| ROE above 15% | Revenue fell in the latest fiscal year |
| Revenue CAGR 3y above 10% | Debt/equity above 2 |
| Debt/equity below 0.5 | Negative shareholders' equity |
| Positive free cash flow | P/E (FY) above 40 |
| Net margin above 15% | Negative free cash flow |

A rule is skipped when its metric is missing or not applicable (so banks never get a debt rule).
Rules live in `backend/pipeline/analysis.py`.
